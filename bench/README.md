# ASR 评测：术语命中率

这里只放**打分工具**，不放语料。金标和音频属于课程内容，各人自己保管。

## 为什么有这个目录

`skills/bilibili-persona/SKILL.md` 里写了「词表修正把术语命中从 71% 提到 100%，同一片段
Qwen3-ASR-1.7B 是 94%」。这组数字来自一次小样本评测，脚本在这里，你可以用自己的课复现。

## 怎么跑

```bash
python bench/score_asr.py --selftest          # 先验证打分器本身
```

1. 切一段 2 分钟音频，用本地转写得到基线文本
2. 以基线为底、**对照课件逐句人工校正**，得到 `gold.txt`
3. 把这段里出现的专业术语一行一个写成 `terms.txt`
4. 打分：

```bash
python bench/score_asr.py gold.txt hyp.txt --terms terms.txt --label "whisper 原始"
```

两个数字回答不同问题：

- **CER**：字符错误率（归一化后去空白标点，保留中日韩字符/字母/数字）
- **术语命中**：清单里有几个术语在文本里出现过。按归一化后的**子串匹配**，所以它回答的是
  「术语有没有写对」，不衡量出现位置是否正确。

## 那次评测的口径与结果

样本：某门专业课 **2 分钟**片段；人工金标 **422 字**；术语 **17 个**。

| 处理 | CER | 术语命中 |
|---|---|---|
| Whisper large-v3-turbo 原始 | 8.06% | 12/17 = 71% |
| ＋3 条针对性词表 | 7.11% | 15/17 = 88% |
| ＋完整 250 条词表 | 5.45% | 14/17 = 82% |
| ＋完整词表＋3 个新词 | **4.50%** | **17/17 = 100%** |
| Qwen3-ASR-1.7B（无词表） | 9.24% | 16/17 = 94% |

速度（同一台机器、GPU）：Whisper 约 **20× 实时**，Qwen3-ASR-1.7B 约 **3.4×**；
后者模型磁盘占用 **4.4GB**。

Whisper 原始漏掉的五个术语：转置、模方、被积函数、厄米算符、点乘；Qwen 只漏「点乘」。

## 三条必须一起引用的限制

1. **单样本**：1 段 2 分钟、17 个术语，不是多样本统计，**不能外推成"总体准确率"**。
2. **金标以 Whisper 输出为底人工校正**：所以 CER 天然偏向 Whisper，**不能读作"谁更准"**。
   术语命中受影响较小（术语是逐个核对的），但仍与金标同源。
3. **100% 那行是确定性替换**（完整词表 + 3 个新补条目），不是 `glossary.py` 自动挖词的
   全自动流程；自动化流程的单独收益尚未评测。

要更强的结论，正确做法是：多段抽样、双人独立标金标、把「谁更准」交给非 Whisper 来源的
第三方文本做裁判。这些还没做。
